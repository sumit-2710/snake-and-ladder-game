# 🎲 Snake and Ladder Game (Python)

A modular and interactive command-line Snake and Ladder game written in Python. The game simulates dice rolls, snake and ladder interactions, and visual feedback using an image-based board. Built for two players, the project follows a clean architecture with separate modules for each functionality.

---

## 📁 Project Structure
snake-and-ladder/ │ ├── main.py # Entry point of the game ├── dicemove.py # Handles dice rolling using Python's random module ├── interface.py # Manages player movement logic ├── snakeboard.gif # Visual board (image-based) ├── README.md # Project documentation



---

## 🚀 Features

- Modular code design for scalability and clarity
- Two-player game simulation
- Dice rolling using `random.randint()`
- Snake and ladder mechanics handled with mapping
- Uses a GIF (`snakeboard.gif`) as a reference for the board

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Modules:** `random`, `tkinter` or `pygame` (if image-based UI is used)
- **Assets:** `snakeboard.gif` (for visual reference)
